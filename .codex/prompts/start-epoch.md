# Epoch 시작

architecture boundary를 바꾸는 작업인지 먼저 판단한다. 아니면 `.codex/context/engineering.md`의 fast track으로 plan 없이 바로 구현한다. epoch 작업이면 `AGENTS.md`, `engineering.md`, 해당 영역의 `.codex/context` 문서, active epoch plan을 읽는다. 편집 전에 현재·목표 source of truth, 제외 범위, 호환성 전략, 리스크, 검증 방법을 확정한다. 하나의 slice에 구현 agent는 최대 두 개만 사용한다.
