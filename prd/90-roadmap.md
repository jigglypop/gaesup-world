## 4. 운영 규칙

- 동시에 진행하는 Epoch는 최대 2개. active plan이 3개를 넘지 않게 한다.
- 각 slice는 독립 병합 가능해야 하며, 병합 전 해당 PRD의 검증 절을 실행한다.
- 공개 API 삭제는 1.x에서 deprecated로 먼저 표시하고, 삭제는 2.0에 모은다.
- 기간은 1인 개발 기준 추정치다. 단계 1과 단계 2의 일부는 병렬 가능하다.
