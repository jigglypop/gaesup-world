# 미니홈피 사용법

[English](minihome.en.md) · [시작하기](../README.ko.md)

**미니룸 꾸미기**에서 최대 40개 가구를 추가하고 드래그로 옮기세요. 선택 목록과 이동·회전 버튼도 있습니다. **꾸미기 완료** 후 바닥 클릭으로 미니미를 이동하고, 오른쪽 드래그로 시점을 바꿉니다.

**프로필 수정**으로 이름·제목·소개·기분을 바꿉니다. 다이어리와 방명록은 이 브라우저에 보관하는 글이며 원격 방문자의 메시지가 아닙니다.

## 저장과 복구

편집은 1.2초 뒤 자동저장됩니다. **미니홈피 저장**은 즉시 저장합니다. 용량 부족이나 다른 탭의 변경이 발견되면 자동저장이 멈춥니다. 충돌하면 현재 작업을 파일로 백업한 뒤 새로고침하세요.

이전 정상 상태는 별도 백업으로 남습니다. 현재 저장본이 손상되면 백업을 표시하고 확인 후 직접 저장하도록 안내합니다. 확인 전에는 자동으로 원본을 덮어쓰지 않습니다. 브라우저 데이터 삭제나 비공개 모드 종료로 저장이 사라질 수 있으므로 중요한 작업은 파일로도 보관하세요.

## 실행 취소와 파일

**실행 취소 / 다시 실행**은 방·프로필·테마·글 변경을 최대 50단계 기억합니다. 새로고침하면 기록은 초기화되고 저장 데이터는 남습니다. 새 편집은 다시 실행 목록을 비웁니다.

**파일 백업**은 전체 미니홈피 JSON을 내려받습니다. **백업 가져오기**는 512 KB 이하의 지원 파일을 검사한 뒤 적용합니다. 잘못된 파일은 현재 방을 바꾸지 않습니다. 가져오기도 실행 취소할 수 있습니다.

## 공유와 Unity

**방 공유**는 프로필과 방만 담은 링크를 만듭니다. 다이어리와 방명록은 제외됩니다. 생성 당시의 사본이며 이후 변경이 자동 반영되지 않습니다. 링크를 열어도 기존 저장은 유지됩니다. **내 방으로 가져오기**는 프로필·테마·방을 가져오고 기존 다이어리·방명록은 보존합니다. 확인 후 직접 저장하세요. 실행 취소하면 가져오기 전 내 방으로 돌아갑니다. 글은 가져온 뒤 작성할 수 있습니다. 긴 링크를 지원하지 않는 서비스에서는 JSON 백업을 사용하세요.

**3D 방 내보내기 (.glb)**는 보이는 geometry와 material을 GLB로 만듭니다. 프로필·글·게임 동작은 포함하지 않습니다. [Unity 연결](unity.md)을 참고하세요.
